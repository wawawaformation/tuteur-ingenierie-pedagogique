# GABARIT : Facettes

Répartir un thème entre plusieurs binômes ou sous-groupes, chacun explorant une dimension complémentaire, puis restituer ces apports afin de reconstruire une vision d'ensemble.

Facettes est une **Activité d'exploration répartie et de restitution croisée**.

Elle ne reprend pas la progression plus complexe d'un dispositif Puzzle / Jigsaw avec groupes d'origine puis groupes d'experts.

## Pourquoi choisir Facettes ?

Choisir Facettes lorsqu'un thème peut être divisé en plusieurs dimensions complémentaires qui gagnent à être explorées en parallèle.

L'activité permet notamment de :

- répartir l'exploration ;
- approfondir plusieurs aspects d'un thème ;
- responsabiliser chaque sous-groupe ;
- faire sélectionner et reformuler l'essentiel ;
- faire bénéficier l'ensemble du groupe des travaux de chacun ;
- reconstruire une vision globale à partir de contributions partielles.

Le point central n'est pas la juxtaposition de mini-exposés.

> Chaque facette doit contribuer à une représentation d'ensemble du thème.

## Niveaux taxonomiques

Facettes se prête naturellement aux niveaux :

- **Comprendre** : reformuler, expliquer et illustrer une facette ;
- **Appliquer** : mobiliser une grille commune ou des notions connues pour explorer cette facette.

Elle peut également mobiliser :

- **Analyser** : distinguer et relier les différentes facettes ;
- **Créer** : produire une synthèse ou représentation collective nouvelle.

## Quand la choisir ?

Elle est adaptée lorsque :

- le thème comporte plusieurs dimensions réellement complémentaires ;
- les sous-groupes peuvent travailler en parallèle ;
- chaque facette possède une richesse suffisante ;
- la restitution de chacune apporte quelque chose aux autres ;
- une synthèse finale peut relier les contributions.

Elle est moins adaptée lorsque :

- les facettes sont artificiellement découpées ;
- certaines sont très riches et d'autres très pauvres ;
- la progression impose de maîtriser une facette avant d'aborder la suivante ;
- chaque groupe peut ignorer les autres restitutions sans conséquence.

## Choisir les facettes

Les facettes doivent être :

- complémentaires ;
- suffisamment distinctes ;
- d'importance ou de charge comparables ;
- directement reliées au thème commun.

Éviter un découpage uniquement destiné à obtenir autant de sujets que de groupes.

## Question directrice commune

Lorsque cela est pertinent, donner aux groupes une même grille d'exploration.

Par exemple :

- de quoi s'agit-il ?
- à quoi cela sert-il ?
- quel exemple ?
- quel point de vigilance ?
- comment cette facette se relie-t-elle au thème global ?

Cette structure rend les restitutions plus comparables.

## Travail en sous-groupes

Chaque binôme ou sous-groupe explore sa facette.

Il doit préparer une restitution courte permettant aux autres de récupérer l'essentiel.

Le formateur veille à ce que les groupes disposent :

- d'un périmètre clair ;
- de ressources adaptées ;
- d'un temps comparable ;
- d'une production attendue identifiable.

## Restitution

Chaque groupe présente sa facette.

La restitution doit rester suffisamment courte pour éviter une succession de longs exposés.

Elle peut prendre la forme :

- d'une présentation orale ;
- d'un schéma ;
- d'un exemple commenté ;
- d'une démonstration ;
- d'une fiche synthétique.

## Activité des autres apprenants

Les autres apprenants ne doivent pas être uniquement spectateurs.

Ils peuvent par exemple :

- compléter une grille commune ;
- noter un exemple ou un point clé ;
- poser une question ;
- identifier les relations avec les facettes déjà présentées ;
- enrichir progressivement une synthèse.

## Reconstruction de l'ensemble

Après les restitutions, prévoir un temps permettant de relier les facettes.

Par exemple :

- tableau de synthèse ;
- carte conceptuelle ;
- schéma ;
- questions transversales ;
- comparaison ;
- construction collective d'une représentation globale.

> La synthèse finale donne son unité pédagogique à l'activité.

## Place du formateur

Le formateur :

- choisit ou valide le découpage ;
- équilibre les facettes ;
- donne une consigne commune lorsque utile ;
- accompagne les groupes sans faire le travail à leur place ;
- régule le temps des restitutions ;
- aide à relier les contributions ;
- corrige les erreurs susceptibles d'être transmises au groupe.

## Risques fréquents

### Facettes déséquilibrées

Un groupe termine très vite pendant qu'un autre doit traiter un sujet beaucoup plus vaste.

### Mini-exposés juxtaposés

Chaque groupe présente sans que les autres aient de tâche ni qu'une vision globale soit reconstruite.

### Transmission incomplète

Une erreur ou une omission dans un sous-groupe peut être propagée aux autres.

### Découpage artificiel

Le thème ne se prête pas réellement à une exploration parallèle.

## Critères de réussite / performance

Ils peuvent notamment porter sur :

- la sélection des éléments essentiels ;
- la justesse de la restitution ;
- la capacité à reformuler ;
- la pertinence des exemples ;
- la capacité à relier la facette au thème global ;
- la participation à la synthèse finale.

## Contrôles avant de livrer Facettes

1. **Finalité** : exploration répartie puis reconstruction d'ensemble.
2. **Complémentarité** : les facettes apportent des dimensions distinctes d'un même thème.
3. **Équilibre** : charge et richesse suffisamment comparables.
4. **Consigne commune** : utilisée lorsque nécessaire pour rendre les productions comparables.
5. **Restitution courte et utile** : pas une suite d'exposés longs.
6. **Activité des auditeurs** : les autres apprenants ont quelque chose à faire pendant les restitutions.
7. **Synthèse finale** : les facettes sont reliées entre elles.
8. **Niveau taxonomique** : il correspond aux opérations réellement demandées.
9. **Pas de confusion avec Puzzle / Jigsaw** : pas de groupes d'experts et de recomposition obligatoires.
10. **Qualité de transmission** : le formateur veille aux erreurs importantes avant qu'elles ne se diffusent.
