# GABARIT : Évaluation par les pairs

Examiner une production à partir de critères explicites, argumenter son appréciation et formuler un retour exploitable.

L'Évaluation par les pairs est une **Activité d'analyse et de jugement d'une production par d'autres apprenants**.

Sa finalité principale n'est pas de déléguer l'évaluation au groupe : elle consiste à faire de **l'acte d'évaluer lui-même une activité d'apprentissage**.

## Pourquoi choisir une Évaluation par les pairs ?

Elle permet notamment de :

- appliquer des critères à une production réelle ;
- distinguer plusieurs niveaux de qualité ;
- identifier des points forts et des points à améliorer ;
- justifier un jugement ;
- formuler un feedback précis ;
- confronter plusieurs regards ;
- affiner progressivement ses critères de qualité ;
- préparer l'autoévaluation.

## Niveaux taxonomiques

Elle se prête naturellement aux niveaux :

- **Appliquer** : utiliser des critères ou une grille ;
- **Analyser** : distinguer les composantes d'une production ;
- **Évaluer** : apprécier une production et argumenter.

Elle peut mobiliser **Créer** lorsque l'apprenant propose une amélioration ou une nouvelle version.

## Quand la choisir ?

Elle est adaptée lorsque les apprenants disposent déjà de suffisamment de repères pour examiner une production.

Elle peut être utilisée pour :

- travailler des critères de qualité ;
- préparer une production finale ;
- améliorer une première version ;
- comparer plusieurs réponses ;
- entraîner l'argumentation ;
- développer l'autoévaluation.

Si les critères sont encore trop peu maîtrisés, prévoir d'abord une calibration ou une analyse guidée.

## Objet de l'évaluation

Préciser ce qui est examiné :

- texte ;
- code ;
- présentation ;
- réponse argumentée ;
- schéma ;
- production graphique ;
- livrable ;
- démonstration ;
- démarche observable.

L'évaluation porte sur **la production ou la performance**, pas sur la personne.

## Critères

Les critères doivent être suffisamment explicites pour guider l'observation.

Ils peuvent être :

- fournis ;
- construits avec les apprenants ;
- partiellement fournis puis complétés ;
- issus d'une grille déjà utilisée.

Un critère vague produit généralement un feedback vague.

## Préparation / calibration

Lorsque nécessaire :

1. présenter une production exemple ;
2. faire évaluer individuellement ;
3. comparer les appréciations ;
4. discuter les écarts ;
5. préciser les critères.

## Consigne / tâche à réaliser

La consigne précise :

- la production à examiner ;
- les critères ;
- la forme du retour ;
- ce qui doit être justifié ;
- la manière dont le feedback sera utilisé.

Éviter :

> Donne ton avis.

Préférer un retour appuyé sur des observables.

## Formuler le feedback

Une structure simple peut être :

### Ce qui répond aux critères

Identifier précisément les éléments satisfaisants.

### Ce qui pourrait être amélioré

Identifier un écart ou une limite et expliquer pourquoi.

### Piste possible

Lorsque pertinent, proposer une orientation permettant de retravailler la production.

## Réception du feedback

Le destinataire peut être invité à :

- identifier les retours pertinents ;
- demander une clarification ;
- comparer plusieurs feedbacks ;
- décider ce qu'il souhaite modifier ;
- produire une nouvelle version.

> Recevoir du feedback n'est pas suffisant : lorsque l'objectif le permet, prévoir une possibilité de l'exploiter.

## Place du formateur

Le formateur peut :

- expliciter les critères ;
- préparer la calibration ;
- vérifier que les retours portent sur les productions ;
- intervenir lorsqu'un jugement repose sur un critère erroné ;
- aider à résoudre des désaccords ;
- synthétiser les enseignements.

## Évaluation formative et certificative

L'Évaluation par les pairs est particulièrement adaptée à un usage **formatif**.

Le jugement d'un pair ne lui confère pas automatiquement l'autorité pour attester une maîtrise ou attribuer un palier.

## Biais et vigilance

Les jugements peuvent être influencés par :

- sympathie ou antipathie ;
- impression générale ;
- première impression ;
- comparaison avec sa propre manière de faire ;
- peur de produire un retour négatif.

Pour limiter ces effets :

- utiliser des critères explicites ;
- demander des observables ;
- faire justifier les appréciations ;
- utiliser plusieurs regards lorsque l'enjeu le nécessite.

## Critères de réussite / performance

Ils peuvent porter sur la capacité à :

- appliquer les critères ;
- identifier des éléments pertinents ;
- distinguer observation et jugement ;
- argumenter ;
- formuler un feedback exploitable ;
- proposer une amélioration cohérente ;
- réviser son jugement si nécessaire.

## Contrôles avant de livrer l'Évaluation par les pairs

1. **Finalité** : l'activité exerce réellement analyse, jugement ou feedback.
2. **Objet explicite** : la production à examiner est claire.
3. **Critères observables** : les appréciations peuvent être fondées.
4. **Niveau de préparation** : les apprenants disposent des repères nécessaires.
5. **Calibration** : prévue lorsque utile.
6. **Production, pas personne** : aucune appréciation globale sur l'apprenant.
7. **Feedback exploitable** : le destinataire sait quoi travailler.
8. **Suite donnée** : une révision est prévue lorsque pertinent.
9. **Niveau taxonomique** : il correspond au travail réellement demandé.
10. **Autorité** : feedback entre pairs et attestation sont distingués.
11. **Biais** : les jugements implicites sont limités.
12. **Budget de nouveauté** : appliquer `../activite_evaluee.md` lorsque nécessaire.
