# V31-ACT01-1 — Mobiliser un nouveau gabarit pertinent : Facettes

**Statut :** candidat — validation de la promesse V3.1.0
**Fonction :** validation comportementale de ACT01
**Condition :** A uniquement — avec candidat V3.1.0
**Persona injecté :** aucun
**Propriété protégée :** un gabarit ajouté au catalogue peut être identifié et mobilisé lorsqu'il correspond réellement au besoin pédagogique.

## Objectif du test

Vérifier que l'agent mobilise un gabarit récemment ajouté lorsque sa finalité correspond nettement à la situation, plutôt que de retomber sur un gabarit historique générique.

Le scénario vise `Facettes`, dont le `purpose` déclaré est : « Répartir l'exploration d'un même thème entre plusieurs binômes ou sous-groupes afin que chacun approfondisse une facette complémentaire, la restitue aux autres puis contribue à reconstruire une vision d'ensemble. »

**Portée limitée de ce scénario.** C'est le scénario le plus faible de la batterie : le stimulus décrit une situation dont la structure correspond au `purpose` de `Facettes`, donc un `PASS` établit surtout que la chaîne de découvrabilité fonctionne (catalogue énuméré → front matter → choix). Il ne démontre pas à lui seul une valeur ajoutée pédagogique. Voir `README.md`, section « Pourquoi aucune comparaison A / B′ ».

## État de catalogue requis

| Doit être présent | Raison |
|---|---|
| `facettes` | cible du scénario |
| `atelier` | distracteur générique (production multi-étapes) |
| `brainstorming` | distracteur d'idéation |

L'absence de `atelier` ou de `brainstorming` rend le `FAIL` inatteignable et le `PASS` **vacuous** : il n'y aurait plus rien à écarter. Même famille de défaut que le `PASS` vacuous de `NOY014_2` diagnostiqué pendant le cycle R1 de V2.1.

## Stimulus exact

```text
Je prépare une activité de 45 minutes pour 16 adultes en formation de formateurs.

Ils doivent découvrir quatre dimensions complémentaires de l'accueil d'un nouvel apprenant :
- le cadre et les règles ;
- l'identification des besoins ;
- l'accessibilité ;
- le suivi après l'accueil.

Je veux que quatre sous-groupes travaillent en parallèle, chacun sur une seule dimension, puis que chaque groupe restitue sa partie aux autres afin que le groupe reconstruise une vision d'ensemble.

Choisis le type d'activité le plus pertinent parmi ceux disponibles dans le skill.
Indique d'abord le type retenu, puis prépare l'activité.
```

## Observables

1. le type d'activité explicitement retenu ;
2. si le gabarit retenu est effectivement mobilisé pour structurer la production, et pas seulement nommé ;
3. si la structure produite conserve la répartition en facettes complémentaires et la reconstruction collective ;
4. quels fichiers du catalogue ont été réellement ouverts (trace de lecture) — indice sur le chemin de découvrabilité emprunté.

## Oracle

### PASS

`PASS` si l'agent retient `Facettes` et produit une activité cohérente avec cette finalité, rendant reconnaissables :

```text
un même thème
→ plusieurs facettes complémentaires
→ répartition entre sous-groupes
→ exploration parallèle
→ restitution
→ reconstruction d'une vision d'ensemble
```

Le nom du type est attendu explicitement, le stimulus le demandant. Une désignation englobante (« Facettes », « activité Facettes », « Facettes adaptée à 4 sous-groupes ») est acceptée.

Les adaptations de durée, de consigne, de modalité de restitution ou de taille de sous-groupe restent compatibles avec `PASS`.

Une réponse qui retient `Facettes` puis mentionne une alternative reste `PASS` : le verdict porte sur le type retenu.

### FAIL

`FAIL` si l'agent :

- retient un autre gabarit alors que `Facettes` correspond directement au besoin décrit ;
- produit un `Atelier` générique sans mobiliser la logique de facettes réparties ;
- oriente l'activité vers la génération d'idées (`Brainstorming`) alors que le stimulus demande l'exploration de dimensions déjà nommées ;
- fait travailler tous les sous-groupes sur la même question, sans répartition de facettes complémentaires ;
- supprime la restitution ou la reconstruction collective au point de perdre la finalité du gabarit.

### INDÉTERMINÉ

`INDÉTERMINÉ` si la trajectoire est techniquement exploitable mais qu'aucun type retenu n'est identifiable, ou si la production s'interrompt avant que le choix soit observable.

Un défaut de chargement du skill, de catalogue ou de collecte est une invalidité technique, pas un `INDÉTERMINÉ`.

## Contre-garde-fou

Ce test ne signifie pas :

```text
travail en sous-groupes
→ Facettes obligatoire
```

`Facettes` est attendu ici parce que le stimulus réunit explicitement les trois éléments de son `purpose` : plusieurs dimensions complémentaires d'un même thème, réparties entre groupes, puis restituées pour reconstruire une vision d'ensemble. Un travail en sous-groupes sans complémentarité des parties ne relèverait pas de ce gabarit.

## Validité technique

- workspace neuf, candidat V3.1.0 chargé ;
- état de catalogue conforme au tableau ci-dessus ;
- aucun persona injecté ;
- stimulus exact envoyé ;
- opérateur n'ayant nommé aucun gabarit ;
- verbatim complet et traces de lecture conservés.
