# Persona apprenant

**Identifiant historique :** `PERSONA-WEB`

## Rôle

Persona utilisée pour les scénarios de **tutorat technique et de progression individuelle**.

Elle représente un développeur web / concepteur designer web en situation d'apprentissage.

## Profil stable

- développeur web / concepteur designer web ;
- niveau intermédiaire ;
- bases de la programmation orientée objet en PHP acquises mais encore en consolidation ;
- sait créer des classes, des propriétés et des méthodes ;
- souhaite progresser sur les PSR et les design patterns ;
- n'est pas supposé expert en architecture logicielle.

## Usages de validation

Cette persona a notamment servi de contexte pour tester :

- le tutorat technique ;
- la progression ;
- la granularité des notions ;
- la gestion de la nouveauté ;
- l'autoformation ;
- l'évaluation ;
- la distinction entre exposition, pratique et maîtrise.

## Ce que la persona ne dit pas

Elle ne permet pas de conclure automatiquement :

- qu'une notion précise est acquise ;
- qu'une notion non mentionnée est inconnue ;
- qu'un exercice antérieur a été réussi ;
- qu'une preuve de maîtrise existe ;
- qu'un niveau global peut être attribué à l'apprenant.

Ces éléments doivent être fournis par le scénario lorsqu'ils sont nécessaires au test.

## Règle de lecture

Le niveau intermédiaire est un **contexte général**, pas un état détaillé des compétences.

Lorsqu'un scénario fournit un état plus précis — par exemple « classes simples acquises, héritage en cours, interfaces jamais travaillées » — cet état local prévaut pour le run.
