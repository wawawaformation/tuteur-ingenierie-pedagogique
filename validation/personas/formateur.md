# Persona formateur

**Identifiant historique :** `PERSONA-FPA`

## Rôle

Persona utilisée pour les scénarios d'**ingénierie pédagogique et de conception de formation**.

Elle représente un formateur en formation préparant le titre professionnel **Formateur Professionnel d'Adultes (TP FPA)**.

## Profil stable

- formateur en formation au titre professionnel **Formateur Professionnel d'Adultes (TP FPA)** ;
- contexte professionnel et pédagogique générique ;
- utilisé pour les tests portant sur la conception d'activités, de séances et d'ateliers.

## Usages de validation

Cette persona a notamment servi de contexte pour tester :

- la conception pédagogique ;
- les activités et séances ;
- les briefs et productions attendues ;
- les critères de réussite ou de performance ;
- les modalités de formation ;
- la visioconférence ;
- l'évaluation ;
- les situations dans lesquelles un cadre ou un référentiel peut devenir pertinent.

## Référentiels : précaution importante

Le fait que la persona prépare le TP FPA **ne constitue pas, à lui seul, une instruction de consulter systématiquement un référentiel officiel**.

Cette distinction est volontaire : certains scénarios peuvent chercher à tester si un cadre officiel est pertinent, s'il doit être vérifié, ou au contraire s'il ne doit pas être déclenché pour une demande ponctuelle.

La persona ne fournit donc pas automatiquement :

- le référentiel officiel complet ;
- une version supposée du référentiel ;
- un bloc ou une compétence officielle ;
- un alignement certifié.

Ces informations appartiennent au scénario lorsqu'elles sont nécessaires.

## Règle de lecture

La persona fournit seulement un contexte professionnel stable.

Le scénario fournit :

- la demande précise ;
- la durée ;
- le public ou l'effectif si nécessaire ;
- les contraintes ;
- les ressources disponibles ;
- le cadre documentaire utile ;
- les éléments à observer ou à évaluer.
