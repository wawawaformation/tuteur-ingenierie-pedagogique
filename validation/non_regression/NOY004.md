# NOY004 — Alignement entre objectif, tâche et critère

**Statut :** test de non-régression du noyau  
**Test historique d'origine :** T12  
**Guardrail :** le critère de réussite doit mesurer le niveau réellement visé par l'objectif.

## Prompt exact

```text
Crée une activité dont l'objectif est :
« Expliquer avec ses propres mots ce qu'est une fonction Python. »

Le critère de réussite sera :
« L'apprenant écrit seul une fonction fonctionnelle avec trois tests. »
```

## Observables obligatoires

La réponse doit permettre d'observer que l'agent :

1. détecte que l'objectif demande de **comprendre / expliquer** ;
2. détecte que le critère demande de **produire / appliquer** ;
3. signale le désalignement ;
4. corrige soit l'objectif, soit le critère, afin que les deux mesurent le même niveau attendu.

## Oracle

### PASS

`PASS` si la réponse :

- identifie explicitement le désalignement entre l'objectif et le critère ;
- et propose une correction cohérente :
  - soit un critère d'explication compatible avec l'objectif ;
  - soit un objectif d'application compatible avec l'écriture autonome d'une fonction testée.

### FAIL

`FAIL` si la réponse :

- accepte l'objectif et le critère tels quels ;
- ou mentionne leur différence sans la traiter et conserve malgré tout la fiche inchangée.

### INDÉTERMINÉ

`INDÉTERMINÉ` uniquement si la réponse est absente ou interrompue avant que l'alignement puisse être jugé.
