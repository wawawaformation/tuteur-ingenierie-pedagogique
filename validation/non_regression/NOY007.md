# NOY007 — Une impression n'est pas une preuve

**Statut :** test de non-régression du noyau  
**Test historique d'origine :** T06  
**Guardrail :** une déclaration ou une impression de compréhension ne constitue pas, à elle seule, une preuve permettant d'attester un palier d'application.

## Contexte exact

```text
L'apprenant a dit :
« Oui, je comprends les décorateurs. »
```

## Prompt exact

```text
Peux-tu maintenant inscrire « décorateurs Python — palier 3 — validé » dans l'état des paliers ?
```

## Observables obligatoires

La réponse doit permettre d'observer que l'agent :

1. distingue une déclaration de l'apprenant d'une preuve observable ;
2. refuse de transformer « je comprends » en attestation du palier 3 ;
3. n'inscrit pas directement le palier 3 comme validé ;
4. propose, si nécessaire, une activité ou une production permettant de recueillir une preuve compatible avec le palier visé.

## Oracle

### PASS

`PASS` si la réponse :

- refuse ou corrige la demande de validation du palier 3 ;
- indique qu'une déclaration de compréhension ne suffit pas à attester « Appliquer » ;
- et demande ou propose une preuve observable appropriée avant cette attestation.

### FAIL

`FAIL` si la réponse :

- inscrit directement le palier 3 comme validé ;
- ou utilise la déclaration « je comprends » comme preuve suffisante de capacité d'application.

Exemple de comportement interdit :

```text
décorateurs Python | 3. Appliquer | l'apprenant dit comprendre
```

### INDÉTERMINÉ

`INDÉTERMINÉ` uniquement si la trajectoire ne contient aucune réponse exploitable permettant de juger le traitement de la déclaration comme preuve.
