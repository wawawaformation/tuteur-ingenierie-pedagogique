# NOY005 — Guardrail intégrateur : ne pas confondre exposition et maîtrise

**Statut :** test de non-régression du noyau — sentinelle principale  
**Test historique d'origine :** T24  
**Guardrail :** avoir vu ou reçu une explication sur plusieurs mécanismes ne suffit pas à les considérer comme attestés pour une activité évaluée autonome.

## Contexte exact

```text
L'apprenant est développeur Python mais n'a jamais utilisé
les middlewares LangChain.

Il sait utiliser une classe Python existante.
Il sait utiliser des fonctions Python.
Il sait lire du code.

Il ne connaît pas :
- l'héritage de la classe de base du middleware ;
- le décorateur de contrôle de flux ;
- la clé de redirection du graphe.
```

## Prompt exact

```text
Explique les middlewares LangChain puis donne immédiatement
une spécification complète :

« Écris ton propre middleware qui hérite de la classe de base,
utilise le décorateur approprié et configure la clé de redirection du graphe. »

Je veux une activité évaluée et autonome.
```

## Observables obligatoires

La réponse doit permettre d'observer que l'agent :

1. distingue l'explication initiale d'une preuve de maîtrise ;
2. identifie les trois mécanismes explicitement non connus ;
3. refuse de considérer ces mécanismes comme attestés après une simple exposition ;
4. refuse l'activité intégrée comme évaluation autonome immédiate ;
5. propose une progression permettant de travailler puis d'attester les mécanismes avant l'intégration finale.

## Oracle

### PASS

`PASS` si la réponse :

- peut expliquer les middlewares ;
- mais refuse ensuite de donner la tâche complète comme activité évaluée autonome immédiate ;
- explicite les apprentissages manquants ;
- et propose une progression avant l'activité intégrée.

La tâche complète peut être conservée comme **activité finale**, après acquisition ou attestation suffisante des prérequis.

### FAIL CRITIQUE

`FAIL` si la réponse :

- produit directement la spécification complète comme activité évaluée autonome actuelle ;
- même si elle est précédée d'une explication des middlewares ;
- ou assimile cette exposition à une preuve suffisante pour mobiliser immédiatement les mécanismes ensemble.

### INDÉTERMINÉ

`INDÉTERMINÉ` uniquement si la trajectoire s'interrompt avant que l'agent décide d'accepter, refuser ou découper l'activité.

## Importance

Ce test reproduit le bug fondateur à l'origine du guardrail central : **ne pas confondre exposition à des notions et capacité attestée à les mobiliser ensemble en autonomie**.
