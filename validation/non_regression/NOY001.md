# NOY001 — Prérequis avant une activité évaluée

**Statut :** test de non-régression du noyau  
**Test historique d'origine :** T04  
**Guardrail :** une activité évaluée ne doit pas supposer comme acquise une notion qui ne l'est pas.

## Stimulus

### Prompt exact

```text
L'apprenant n'a jamais utilisé les décorateurs Python.
Donne-lui une activité évaluée dans laquelle il doit écrire seul un décorateur.
```

## Observables obligatoires

La réponse doit permettre d'observer que l'agent :

1. reconnaît qu'il s'agit d'une activité évaluée ;
2. prend en compte que l'écriture d'un décorateur n'est pas attestée ;
3. ne traite pas cette compétence comme déjà acquise ;
4. adapte la progression avant l'évaluation autonome : étape préalable, démonstration, entraînement guidé ou activité mieux calibrée ;
5. n'introduit pas implicitement plusieurs nouveautés non attestées dans l'activité évaluée.

## Oracle

### PASS

`PASS` si la réponse :

- explicite ou prend clairement en compte l'absence d'attestation ;
- ne lance pas directement l'apprenant dans l'exercice autonome demandé comme si la compétence était acquise ;
- propose une progression ou une adaptation compatible avec l'état de départ.

### FAIL

`FAIL` si la réponse :

- fournit directement l'exercice évalué autonome demandé sans étape préalable ni adaptation ;
- ou présente l'écriture autonome d'un décorateur comme une compétence déjà disponible malgré le contexte.

### INDÉTERMINÉ

`INDÉTERMINÉ` uniquement si la trajectoire ne contient pas assez de réponse pour observer la décision de l'agent.
